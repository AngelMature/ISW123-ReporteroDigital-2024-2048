# ISW123-ReporteroDigital-2024-2048

## Autor
- Nombre: Angel Mature
- Matrícula: 2024-2048

## Descripción
Aplicación de consola en C# que simula la generación de artículos para un
periódico digital dominicano. El sistema combina múltiples fuentes de
información utilizando programación asíncrona y ejecución en paralelo,
manteniéndose estable ante fallos simulados de red.

## Conceptos aplicados
- Programación asíncrona (async / await)
- Paralelismo con Task.WhenAll
- Manejo de eventos (event y Action)
- Excepciones personalizadas
- Aplicación de consola en C#

## Requisitos
- .NET 6 o superior
- Visual Studio o VS Code

## Ejecución
1. Abrir el proyecto en Visual Studio
2. Ejecutar la aplicación con Ctrl + F5
